# 🏠 Smart-Home: Envío de Datos a la Nube
**Proyecto de IoT e Infraestructura Digital**

Sistema desarrollado en **Python** para la captura de datos de sensores y su posterior envío/sincronización con plataformas de bases de datos y análisis en la nube.

---

### 🚀 Funcionalidades Clave:
- **Conectividad Cloud:** Integración con **Supabase** para almacenamiento persistente de datos.
- **Visualización en tiempo real:** Envío de métricas a **Thinkspeak** para monitoreo remoto.
- **Automatización:** Script optimizado para la lectura constante de puertos y gestión de excepciones de red.

### 🛠️ Stack Tecnológico:
- **Lenguaje:** Python 3.x
- **Librerías principales:** `requests`, `pyserial` (o la que uses para el puerto), `json`.
- **Servicios:** Supabase (Backend as a Service), Thinkspeak (IoT Analytics).

### 📋 Requisitos e Instalación:
1. Clona el repositorio:
   ```bash
   git clone https://github.com
   ```
2. Instala las dependencias:
   ```bash
   pip install -r requirements.txt
   ```
3. Configura tus credenciales en los scripts `GetData.py` o mediante variables de entorno.
